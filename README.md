## 🚀 About The Project

> **AI Medical Assistant Web** redefines digital healthcare by merging high-performance frontend architecture with intelligent diagnostic workflows. 

Designed with a heavy focus on modern aesthetics, the platform integrates striking **glassmorphism UI patterns**, fluid **3D animations**, and robust state management to deliver an engaging, secure, and lightning-fast user experience.

---

## 💎 Core Features

* **🤖 Intelligent Symptom Analysis:** Advanced AI-driven evaluation system designed to process user symptoms and deliver instant preliminary insights.
* **🎨 Immersive UI/UX Ecosystem:** Built utilizing custom CSS 3D transforms, glowing dynamic gradients, and frosted glass container cards.
* **👤 Dynamic User Portal:** 
  * Seamless profile management and personal data handling via `PersonalInformation.tsx`.
  * Comprehensive diagnostic breakdowns, risk scoring, and result tracking via `SymptomsResult.tsx`.
* **⚡ High-Performance Architecture:** Optimized component rendering cycles, responsive layout rules, and seamless client-side routing.

⚙️ Getting Started
Follow these steps to set up and run a local copy on your machine:

📋 Prerequisites
Ensure you have the following installed:

Node.js (v16.0 or higher)

npm or yarn package manager

Git command line tools

1️⃣ Clone the Repository
Bash
git clone [https://github.com/LokeshVaswani001/ai-medical-assistant-web.git](https://github.com/LokeshVaswani001/ai-medical-assistant-web.git)
2️⃣ Navigate to the Directory
Bash
cd ai-medical-assistant-web
3️⃣ Install Dependencies
Bash
npm install
4️⃣ Set Up Environment Variables
Create a .env file in the root folder using the template provided below.

5️⃣ Run the Development Server
Bash
npm run dev
Access the local application at: http://localhost:5173

🔐 Environment Configuration
Create a .env file in the root directory with the following variables:

Code snippet
VITE_API_BASE_URL=your_backend_api_url_here
VITE_AI_MODEL_KEY=your_ai_integration_key_here
